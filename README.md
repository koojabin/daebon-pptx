# 대본.pptx

PPT 파일을 올리면 생성형 AI가 **슬라이드별 발표 대본**과 **교수님 스타일에 맞춘 예상 질문**을 만들어 주는 웹앱입니다.
생성형 AI 활용 수업의 미니 프로젝트입니다.

👉 **사용해 보기: https://koojabin.github.io/daebon-pptx/**

## 사용 방법

1. `.pptx` 파일을 올립니다. (파일은 브라우저 안에서만 읽고 서버로 올라가지 않습니다)
2. 추출된 슬라이드 내용을 확인하고, 이미지 위주 슬라이드는 보충 메모를 적습니다.
3. 발표 시간, 교수님 스타일, 말투를 정합니다.
4. AI 사용 방법을 고릅니다.
   - **API로 생성**: Claude / OpenAI / Gemini 중 하나를 고르고 API 키를 입력합니다. Gemini는 [Google AI Studio](https://aistudio.google.com)에서 무료 등급 키를 받을 수 있습니다.
   - **직접 붙여넣기 (무료)**: 프롬프트를 복사해 ChatGPT·Claude·Gemini 웹 채팅에 붙여 넣고, 받은 JSON 답을 앱에 다시 붙여 넣습니다.

## 결과 화면

- 슬라이드별 대본
- 예상 시간: AI가 추정한 값 + 한국어 발화 속도(분당 약 280자) 기준 값, 목표 시간을 넘으면 경고
- 교수님 스타일 기준 예상 질문 3~5개와 답변 방향
- 설정을 바꿔 다시 생성하면 이전 결과와 나란히 비교
- 대본 전체 복사 / `.txt` 다운로드

## 구조

빌드 도구·프레임워크·서버 없이 순수 HTML/CSS/JavaScript로 만들었습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `app.js` | 업로드, PPT 파싱(JSZip), 화면 갱신, API 호출 |
| `prompts.js` | AI에 보내는 프롬프트 템플릿 |
| `docs/prompt-log.md` | 프롬프트 개선 과정과 AI가 틀린 부분을 고친 기록 |
| `docs/발표자료.pptx` | 프로젝트 발표 자료 |

API 키는 페이지 메모리에만 두고 어디에도 저장하지 않습니다.
